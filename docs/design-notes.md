# 最初の試作

完成デザインではなく、ゆうちゃんと見ながら育てるための第一案です。

## 画面

- ブランド名「ハルノヒト」を最も大きく表示。
- 「ちいさなデジタル工房」は小さな肩書き。
- 提供された線画の色になじむ、温かい紙色の背景。
- PCは左に文字、右に女の子。スマートフォンは上に文字、下に女の子。
- 原本の透明な余白を含む16:9の共通ステージ。女の子も花びらも同じステージ全体に配置するため、元画像の解像度差で位置がずれません。
- スマートフォンは共通ステージ自体を拡大・配置して余白をトリミングします。女の子の左右端は画面内に残し、元画像の下端は加工しません。

## 動き

名前は一文字ずつ、0.19秒の時間差で小さく浮かび上がります。
桜は2枚から始まり、24秒までかけて10枚が順に登場します。各出現には3.8秒かけます。
23〜35秒の異なる周期で、ごく小さく往復・回転します。
スマートフォンは6枚に絞り、移動量を減らします。
今回は複製を加えず、元の10素材をそれぞれ独立して使っています。

## 次に調整する候補

桜の速度・数・配置・出現時間、名前の大きさ・位置・動き、肩書きの位置、女の子の見え方。
`scripts/main.js` の配列は桜1〜10の順です。
`delay` が出現時刻、`duration` が片道の移動時間、`dx/dy` がステージに対する移動率です。
`mobile` がスマートフォンで表示するかどうかです。
